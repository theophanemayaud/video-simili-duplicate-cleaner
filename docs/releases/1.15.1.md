# 1.15.1 patch release

Fixes [issue #220](https://github.com/theophanemayaud/video-simili-duplicate-cleaner/issues/220):
Ogg audio with embedded cover art is skipped instead of crashing during thumbnail seeking.
Metadata and capture both exclude attached pictures and timed thumbnails. Normal videos
with cover art remain supported; existing partial metadata caches are also protected.
No dependency changes or cache migration are required.

## Validation gates

- Run the self-contained CTest baseline from `AGENTS.md` on macOS.
- Require the PR's Linux and all four macOS test jobs to pass.
- Dispatch `Windows package` on the PR branch. Its x64 job runs
  `test_failed_video_cache` against the release dependencies before uploading packages.
  Require both architecture jobs and the bundle job to pass.
- Confirm release metadata is 1.15.1 on macOS and 1.15.1.0 in both Windows manifests.

The two small issue-220 fixtures and their provenance are documented in
`samples/videos/issue-220-fixtures.md`. The regression checks cover uncached extraction,
failure caching, partial cached metadata, and real video with attached cover art.

## Finalize and submit

Squash-merge the fix PR using its Conventional Commit title. Build/dispatch again on the
merged commit if its contents differ from the validated PR head. Create tag `v1.15.1`
only after the validation gates pass. The version bump and changelog are already in the
PR; do not run `npm run release:patch` again, which would advance to 1.15.2.

Windows: download `windows-msixbundle` from the successful `Windows package` run
and submit the **unsigned** bundle to Partner Center. Artifacts expire after two days;
redispatch on the release commit if needed. Local sideload signing is only for disposable
VM testing, as described in `DEPLOY.md`.

macOS: `npm run binaries` is the standard release build/sign/package path, using the
existing Apple Distribution and installer identities. It also kills the running app and
replaces sibling artifacts, so coordinate that step with any active app session.
For an isolated build without those side effects:

```sh
npm run update-build-version
npm run build-binaries-cmake --prefix QtProject/release-build/macos
```

This produces the universal app, DMG, and signed App Store PKG within the worktree.
Valid Apple Distribution and `3rd Party Mac Developer Installer` certificates and private
keys must be available in the keychain for the signing steps. An unsigned local build or
PKG is validation output, not an App Store submission artifact.

Use `docs/releases/1.15.1-store-notes.md` for both stores. Store submission and public
release publication remain separate actions after validation and approval.
